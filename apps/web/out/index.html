End-to-End Workflow

7 Steps from Deal Registration to Unloading

Standardized procedure enforced across all terminal stations in Nigeria.

01

Deal Registered

Admin registers client contract, auto-generates Consignment ID and tracking reference.

02

Wagon Allocation

Matching locomotive and box/hopper wagons allocated to the cargo manifest.

03

Loading at Origin

Cargo Officer logs loading start time, wagon manifest, and commodity volume.

04

Corridor Transit

GPS satellite + railway checkpoint beacon streams live train position.

05

Arrival at Yard

Destination supervisor alerted. Offloading slot assigned immediately.

06

Unloading Audit

Actual bag count compared to manifest. Discrepancies flagged instantly.

07

Manifest Cleared

Automated discrepancy report filed. Consignment officially completed.
